  cd "C:\Users\Administrador\Desktop\AMSA\Personal\Proyectos IA\GLPI-Agent"
  python bot_24_7.py


VER LOGS EN TIEMPO REAL:
  Get-Content "C:\Users\Administrador\Desktop\AMSA\Personal\Proyectos IA\GLPI-Agent\logs\bot_24_7.log" -Wait -Tail 20


DETENER EL BOT:
  Get-Process python | Where-Object { $_.CommandLine -like "*bot_24_7*" } | Stop-Process


REINICIAR EL BOT:
  1. Stop-Process -Name python -Force
  2. Start-Sleep -Seconds 2
  3. python bot_24_7.py

❌ El bot no responde:
   1. Verifica que esté corriendo: Get-Process python
   2. Revisa logs: Get-Content logs\bot_24_7.log -Tail 30
   3. Reinicia: Stop-Process -Name python; Start-Sleep 2; python bot_24_7.py

❌ Error de token de Telegram:
   → El token en .env debe ser válido
   → Ejecuta: python test_bot_interactive.py (para validar configuración)

❌ Error de conexión a GLPI:
   → Verifica credenciales en .env
   → Comprueba: https://soporte.promed.com.py
   → Prueba: python main.py --test-glpi
