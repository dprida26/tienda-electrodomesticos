════════════════════════════════════════════════════════════════════════════

COMO FUNCIONA:

1. npm start                  ← Inicia agente + API
2. Otros agentes llaman:      http://localhost:3000/api/v1/*
3. Reciben respuesta JSON     ← Datos procesados

════════════════════════════════════════════════════════════════════════════

11 ENDPOINTS DISPONIBLES:

GET  /health                           Verificar que está activo
GET  /api/v1/status                    Estado del agente
POST /api/v1/reports/generate          Generar reporte hoy
POST /api/v1/reports/generate-range    Reporte (rango de fechas)
GET  /api/v1/emails?days=N             Obtener correos
GET  /api/v1/linkedin/notif?days=N     Obtener LinkedIn
GET  /api/v1/reports                   Listar reportes
GET  /api/v1/reports/:filename         Descargar PDF
POST /api/v1/reports/gen-with-callback Generar con webhook
POST /api/v1/events                    Sistema de eventos
GET  /api/docs                         Documentación JSON

════════════════════════════════════════════════════════════════════════════

USO DESDE OTRO AGENTE (JavaScript):

const { NotificationsAgentClient } = require('./sdk/client');
const client = new NotificationsAgentClient('http://localhost:3000');

// Generar reporte
const result = await client.generateReport();

// Obtener correos
const emails = await client.getEmails(7);

// Obtener LinkedIn
const notifications = await client.getLinkedInNotifications(7);

CASOS DE USO:

Orquestador: Coordina múltiples agentes

Worker: Job que genera reportes periódicamente
Monitor: Agente que verifica salud de otros
Pipeline: Procesa emails de forma automática

FLUJOS SOPORTADOS:

1. DIRECTO (Síncrono)
   Agente A → POST /reports/generate → Respuesta JSON

2. WEBHOOK (Asincrónico)
   Agente A → POST /gen-with-callback → taskId
   Agente A espera webhook cuando esté listo

3. EVENTOS (Pubsub)
   Agente A → POST /events (GENERATE_REPORT) → Respuesta
